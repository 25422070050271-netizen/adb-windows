# YICEE STUDIO — Desde las sombras, diseñamos lo que trasciende.

> Ideas silenciosas. Visuales que permanecen.

Estudio creativo basado en Querétaro, MX. Trabajamos en silencio para construir marcas que no necesitan gritar para imponerse.

**Live:** yicee.studio
**Stack:** Next.js 15 + Tailwind v4 + Framer Motion + Lenis

---

### Manifiesto

>
> YICEE STUDIO opera en silencio. No buscamos ruido, buscamos resonancia. Pensado en la sombra. Creado para perdurar.

### Features

- [x] Diseño quiet luxury 2026 - solo neutros
- [x] 100% en español
- [x] Sistema de actualizaciones sin código
- [x] Admin panel en `/admin`
- [x] Bento grid + marquee + smooth scroll
